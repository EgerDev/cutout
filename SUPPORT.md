# Getting help

- **Questions and ideas:** start a [discussion](https://github.com/EgerDev/cutout/discussions)
  or open an [issue](https://github.com/EgerDev/cutout/issues).
- **Bugs:** open an [issue](https://github.com/EgerDev/cutout/issues) with the browser and
  version, the device, what you did, and what happened. If a particular image triggers it,
  say what format it is; attach it only if it contains nothing private.
- **Security problems:** report them privately as described in [SECURITY.md](SECURITY.md).

Issues and discussions are public. Do not post personal information, private photos or
anything else you would not want published.

Cutout is maintained in spare time, so answers can take a while. There is no paid support.
